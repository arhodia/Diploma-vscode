# Diploma Thesis Project  
**Development of a Cloud Platform for Efficient Matching between Academic Researchers and Innovation Startups using Machine Learning and NLP**

This repository contains the implementation of my diploma thesis.  
The project includes a backend (PySpark, Machine Learning) and a frontend (React) that together provide a platform for matching researchers with startups based on clustering and similarity analysis.
